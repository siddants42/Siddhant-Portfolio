# Siddhant Pathak — Editorial Portfolio

A responsive, animated developer portfolio for Siddhant Pathak.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Included in this revision

- Professional Siddhant profile photo in hero and About sections
- Software Developer positioning (Python is included as a skill, not the headline)
- Delhi, India location
- EOXS and SY Associates experience
- Editorial/blog-inspired layout
- Animated rotating hero words
- Moving technology marquee
- GSAP scroll reveals and subtle hover motion
- Lenis smooth scrolling
- Responsive navigation and mobile layouts
- Structured skills section
- Custom project showcase artwork for all four projects
- Dark/light theme
- Contact section redesigned to match the site palette instead of red
- Reduced-motion accessibility support
